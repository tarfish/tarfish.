# Features:

+ welcomes new people who join my personal channel in the hackclub slack, gives them some lore about the channel, and gives them the ability to ping me (just makes the channel quite lively)
+ sends a "good morning!" message in the morning every day
+ allows people with permission to send messages AS the bot if the bot and the user with perms are in the channel. this feature works for threads also (`/tarfish-send "message"` or `?s "message"`)
+ summarizes my day with a lot of cool features like the songs or games i played that day (wip)
+ actually responds when you ping it in a thread
+ `/tarfish-help` opens a convenient help section that tells you it's commands
+ `/tarfish-ping` can be used to check the latency of the bot
